# 操作手册

## 租户管理

系统超级管理员在「系统管理 → 租户管理」中按名称、状态查询租户。

新增租户需填写名称、管理员账号和初始密码。保存后同时创建根部门和首任管理员；初始密码不再回显，请通过组织认可的方式交给管理员。创建失败时先查看页面错误，再修正输入。不要因等待响应而重复提交。创建结果的租户编码可在列表查看；首任管理员在登录页填写账号、初始密码和该编码即可进入对应租户。同名账号必须填写编码，原有不重名账号仍可留空登录。

「管理员维护」只操作该行所属租户。可以选择该租户中仍有效、持有管理员角色的账号；未配置管理员的存量租户也可填写账号和初始密码，创建并关联首任管理员。列表按已保存的管理员关联显示，账号改名或增加其他管理员不会改变该关联。初始密码只在创建时提交，保存后不回显。

创建租户时，同一新增窗口内的失败重试会沿用原操作标识；重复请求返回同一创建结果。提交期间请等待当前结果，重新打开新增窗口代表另一项创建操作。

普通租户可以修改名称、停用或重新启用。启停时需填写变更原因；系统记录操作者、原因、时间和结果。租户 0 是保留对象，只能查看。停用后的业务准入与恢复结果以服务端返回为准；有效期届满也会留下状态记录。

## 应用管理与排列

在「应用管理」中输入应用名称并按回车查询。应用卡片右上角的「更多」菜单提供编辑和删除；有目录或表单引用的应用需先处理这些归属，删除失败时会保留应用。

点击「新建应用」，填写名称后选择图标和颜色。图标支持按中文名称或图标标识搜索；颜色可以选预设色，也可以填写完整的六位 HEX 值。两个选择窗口分别确认，取消只丢弃当前选择窗口的修改，已填名称和另一项外观继续保留。最后点击应用窗口的「保存」才会提交整个配置。

「可见范围」入口可展开用户、部门、角色、岗位和租户等既有范围配置。新建应用默认选择创建者；修改外观时原有范围继续保留。应用是否可见与表单数据的读写权限分别校验。

工具栏的排列按钮可选择每行 3、4、5、6 或 8 个应用，应用中心与应用管理共用这一偏好。选择只影响当前浏览器的排列，刷新后保留；浏览器不允许保存偏好时，本页仍可切换。窄屏会调整列数，卡片名称过长时可查看完整名称。

## 主题

顶栏「主题」可选择默认紫、蓝、青或自定义颜色。先查看窗口内预览，点击「完成」后应用；关闭窗口会取消本次预览。「恢复默认」也需点击「完成」才生效。自定义颜色需写成六位 HEX，例如 #B45309。

主题偏好保存在当前浏览器中，刷新后恢复。清除浏览器站点数据后会回到默认主题。

## 脚本编辑与预览

表单字段与流程配置共用脚本窗口。左侧可按函数名、分类或说明搜索；点击函数名会把示例插入当前光标或替换选中内容。问号和下方说明区展示所选函数的用途与示例。函数目录随当前配置场景变化。

「清空」需确认，取消保留当前草稿。「应用」把草稿带回配置页，之后仍需保存定义；关闭或点击「取消」会丢弃本次未应用的修改。

「运行」在独立预览区显示返回值、调用记录或错误。预览不提交表单，也不保存配置。表单字段预览使用示例值，只支持变量声明、条件、返回、基础表达式和目录函数，不提供浏览器对象或任意 JavaScript 环境；流程预览由流程脚本服务处理，变量使用预览样例。实际组织查询仍受当前身份权限限制。

修改脚本、关闭窗口或离开配置页会取消当前预览；超时会显示错误并释放运行状态。重新打开窗口会恢复配置页传入的脚本并清除旧结果。

## 超管创建与编辑用户、部门的租户归属

超管可在用户、部门页按所属租户查询。选择一个租户并查询后，新建窗口继承该目标；查询全部租户时，先选择可用租户，再填写对象。窗口内的租户名称只读。停用或过期租户可查询，其新建和管理写入会被拒绝；需要先在租户管理中恢复可用状态。

编辑始终使用对象本身的租户。部门父级、负责人、用户主部门、角色、岗位及任职部门只能选择同一租户的对象。用户及角色、任职一次保存，关联无效时整个保存失败。普通账号按登录租户创建和编辑，不显示全局租户选择入口。全部租户的部门树按租户分组，分组标题只用于查看。

## 发布快照

进入表单工作台，点击「版本」打开历史版本，选择版本后点击「查看完整快照」。左侧可以切换字段、脚本、校验、显隐、列表列配置、权限、节点、变量、触发器和审批人脚本；所有内容只读。概览列出对应的表单版本和关联流程版本，原始配置可展开查看。

快照显示发布时保存的配置。旧版本没有保存的内容会显示空态；关联流程读取失败时会显示错误，重新打开窗口可重试。修改现行列表配置后，需发布新版本才会进入新快照，既有快照保持原值。

## 审批与加签

任务详情底部提供退回、驳回和同意。转办、委托、沟通及加签等操作位于「更多」，可用动作取决于当前任务、节点策略和账号权限。「暂存」只保存当前办理人的意见草稿，重新打开同一待办可恢复；暂存不会推进任务，也不要求意见表单已填完整。

加签时分别选择位置和多人顺序。前加签先等待追加人员确认，再由原办理人继续审批；后加签携带原办理意见，追加人员确认后按该意见推进。串行按人员顺序逐个确认，并行允许各人分别确认。追加人员在「待办任务」的待确认列表中查看并表态，串行前序未完成时后序不能提前确认。

人员选择显示姓名并保留原始账号标识；同名时请结合账号核对。任务完成后不能修改原意见草稿；补签记录补充确认事实，保留原实例终态。

## 表单权限、列表与校验

在表单工作台的「权限」中配置字段查看、编辑和表单动作的可用主体。保存并发布后，填写、查看和服务端请求按这些规则检查；隐藏字段或调整个人列偏好不会增加数据权限。

默认列表配置决定展示列、筛选项、默认排序和列表动作；个人排列只影响个人视图。修改后保存配置，并在发布新版本后核对快照。字段的最小长度、最大长度、正则和提示在属性区设置，发布时会检查规则是否合法；提交、更新和导入继续由服务端校验。长度按字符计算，表情等非 BMP 字符计为一个字符。草稿暂存允许必填项未完成，正式提交仍需满足校验。

子表通过字段弹窗维护明细字段，在清单中调整顺序和显示、必填、编辑属性。保存后重新打开核对配置，发布后用实际明细行检查必填与长度边界。

控件库的「关联数据」从已授权的表单中选择记录，「数据源」使用已授权的外部查询。

外部数据源由有管理权限的人员维护，表单只选择已授权的数据源和查询。连接秘密只写入服务端保护配置，不会在表单定义和连接详情中回显。数据源停用、连接失败或权限不足时，先根据错误修正配置，再重试；不要把连接信息写进脚本。

## 表单事件

工作台的「事件」分别配置加载完成、提交前、提交后动作，可调整顺序、启停和脚本。保存后发布，实际填报使用该发布版本的事件。

加载完成事件在字段初始化之后运行；提交前事件在最终校验前运行，出错、取消或超时会阻止提交。修正输入或脚本后可重新操作。草稿和意见暂存不会触发正式提交事件。

提交后事件只在业务已确认提交成功后运行。若此时脚本失败，按提示重试后续动作，避免再次提交同一业务。响应尚未明确时先查看原操作结果，不创建新的提交。脚本只能调用目录提供的函数，字段权限和组织、流程及集成权限仍由平台检查。

## 智能体节点与模型连接测试

节点属性区的问号保留配置规则，可悬停、用 Tab 聚焦或点击查看。循环节点最多迭代次数留空时使用默认值 10，填写时至少为 1；循环头只允许一条出边进入循环体，超过次数上限会报错。

条件节点按出边关键词选择路径；关键词留空代表默认路径，只能保留一条。并行分支至少需要两条出边，各分支可在汇合节点等待全部到达后继续；汇合节点至少需要两条入边。

模型配置中的连通测试显示当前配置、可达结果、测试消息和探测耗时。失败时根据当前错误检查地址、模型和连接配置，再重试。返回消息和实际成功、失败状态继续显示在测试结果中。

## 表单公式与默认列表

公式通过「${name}」引用字段；支持的运算和函数见公式输入框示例。提交后的公式结果按表单已发布版本计算，填写时的显示结果不替代最终计算。修改公式后需发布才对新提交生效。

默认列表决定有权限用户首次打开数据页时的展示列、筛选、排序和操作。用户个人调整的显示偏好不会写回默认列表。动作权限配置只允许指定主体执行已配置动作；没有配置的动作继续沿用原有页面与接口权限。

## 流程监听与子流程批次

流程发起监听在流程建立后执行，流程结束监听在合法最终状态提交后执行。节点事件在对应节点属性中配置。监听配置随流程版本发布，历史实例仍使用其启动时的版本。

批次详情显示等待策略、预期与已结算数量、父流程层级。等待策略包括全部、任一、指定数量与不等待；指定数量按已完成有效回写的子流程数计算，失败、冲突、拒绝及迟到结果不计入；这里统计子流程，不是审批人数。已结算或已取消批次的历史诊断仅用于追溯，不表示当前仍受阻断。

## 批量调用与资源策略

批量调用按批次受理，受理成功不表示全部业务项已完成。每批包含 1—500 项，项键在批次内唯一；提交后按批次键回查状态及各项结果。重试时保留原批次键和项键，已经成功的项不会再次执行。记录标识、数量及动作权限仍按实际受控动作校验。

资源策略由有管理权限的人员创建和启停，新策略初始关闭。生产保留、普通 OA 保留及共享容量之和须等于全局上限；启用前平台检查份额、执行服务可用性与预算相容性，失败时保持原状态并显示原因。策略启用仅影响后续新受理，在途对象继续按受理时的策略版本结算。

资源积压页分别显示命令与流程引擎任务的积压、配额占用及拒绝记录；统计窗口和完成口径以页面当前返回的说明为准。先区分待处理、正在执行、已失败和待核实，再结合对应对象的记录处理，不把接受请求等同于业务完成。

## 附件与图片

打开已保存记录的详情，点击附件右侧「下载」。图片可直接预览；预览失败时可尝试下载。若提示无权访问，请联系记录负责人确认记录和字段的查看范围；文件已删除时需重新上传。

## 富文本字段

富文本字段使用工具栏设置字体、字号、颜色、加粗、斜体和下划线；正文区域可直接输入、换行和粘贴。粘贴内容会按平台允许的格式清理，脚本、样式、事件、链接和图片不会进入保存值。旧记录中按纯文本保存的内容继续按原文字显示，不会因为打开编辑器变成 HTML。

必填、长度和正则按实际可见文字判断，不把排版标签算进长度。保存后服务端会再次清洗并保存清洗结果；以详情或历史版本中显示的内容为准。需要精确复现时，先保存再重新打开核对，不要只在编辑器中看样式。

## 流程设置与结束通知

在流程设计器工具条点击「流程设置」进入独立设置页。左侧「通知」配置流程结束对象：发起人、审批人，以及可多选的其他接收人；渠道至少选择一个，站内信可直接在通知中心查看，邮件是否送达以租户现有邮件配置为准。没有配置接收对象或渠道时保存会提示，不会写入空配置。设置页保存的是草稿，仍需回流程设计器发布才对新实例生效。

「事件监听」页签只读列出现有触发器，编辑入口仍在流程设计器。通知配置随流程版本冻结：旧实例保持启动时的版本，新发布版本使用新配置。其他接收人必须是当前租户有效用户，跨租户人员会在发布时被拒绝。

## 节点高级

选中审批节点后，右侧属性面板的「高级」页签集中放置节点脚本、子流程、审批意见表单和操作设置。节点脚本分开始前和结束后，使用统一脚本窗口编辑；子流程在审批节点上配置发起目标，等待块由设计器生成；审批意见表单选择该节点使用的意见模板；操作设置决定本节点可用的同意、驳回、退回、转办、委托、沟通、加签等动作。未设置操作时沿用既有策略，清空后不允许审批操作。

高级页签只负责把这些既有能力放到一处；保存后仍需发布。发布快照会冻结脚本、子流程、意见表单和操作设置，旧版本不会追溯。

## 工作台与我的门户

工作台默认展示待办、我发起的、快捷发起、业务动态和效率统计。点击「布局」可调整卡片位置和大小；保存后按当前账号恢复，点击「恢复默认」清除个人布局并回到默认排列。自定义布局不会再自动补回已移除的卡片。待办行显示真实期限和「办理」入口；快捷发起从流程中心选择常用事项。

「我的门户」按当前账号权限展示可发起服务、待办概览和最近动态。卡片数量受权限和租户配置影响；没有可用服务时显示空态，不显示无权限的入口。门户与工作台共用当前登录身份，切换账号后重新加载。

## 租户管理的权限边界

租户管理只允许租户 0 的系统超级管理员维护。普通租户管理员打开「系统管理 → 租户管理」时会看到「仅系统超级管理员可以维护租户」，页面不会发起租户列表请求；这是权限限制，不是网络或参数错误。需要维护租户时，请使用系统超级管理员账号。

超级管理员新增租户、维护管理员、启停租户的规则见前文「租户管理」。普通租户内的用户、部门、角色等管理不受此入口影响。

## 脚本函数目录的使用

表单字段脚本和表单事件共用函数目录，目录按当前场景展示分类与示例。可在搜索框按函数名、分类或说明筛选，点击函数名插入到光标处。主表支持批量取值和清空，明细支持行级读写、行数、行标识、新增、删除、批量列值和汇总，表单上下文支持读取表单标识、版本、提交结果、当前租户和角色；集成调用只对已授权集成可用，未授权会明确拒绝。

「运行」只做预览，不提交表单、不推进流程、不保存配置。预览中的组织、角色和集成查询仍受当前账号权限限制；预览成功不代表正式提交一定成功，正式结果以保存或提交后的页面提示和服务端记录为准。
